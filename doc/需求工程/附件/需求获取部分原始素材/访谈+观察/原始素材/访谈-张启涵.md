### 二、 访谈提纲内容

#### 1. 暖场与背景了解 (5-10 min)
* 您平时主要的写作任务有哪些？（如：实验报告、期刊论文、毕业论文、课程笔记）
* 您目前最常用的写作工具链是什么？（例如：Word + Zotero + ChatGPT / Overleaf + VS Code）
* **追问**：为什么选择这个组合？在切换工具时，最让你烦躁的操作是什么？

A、主要的写作任务目前只有实验报告和毕业论文，写作一般就word+gpt或者豆包啥的
B、写作任务当然就是论文初稿的撰写，具体的工具链应该算是word+notebook+ppt+gemini吧。切换工具的时候很烦的就是屏幕太小装不下，无法平铺所有视图之类的。

#### 2. 文献阅读与笔记痛点 (15 min)
* 当您拿到一份 PDF 文献时，通常的操作流程是怎样的？
* 在阅读 PDF 时，您如何记录笔记？（纸质、侧边栏注释、还是另开一个 Markdown 窗口？）
* **关键点拨**：有没有遇到过“看完 PDF 却找不到笔记位置”或者“想引用 PDF 里的公式却要手动手打”的情况？频率高吗？

A、先看阿 如果有目录就从目录里找与我需求有关的点跳着读 记笔记另开一个
有时候引用公式会遇到麻烦
B、拿到文献的时候我会先注明这是属于哪种我需要看的文献，比如说我需要重点关注他的实验部分或者图示部分之类，然后把他们导入notebook里让ai帮我归纳一下。大概知道文章大意就会去仔细看对应位置。而不是通读全文。至于记笔记，我不会记笔记的，有关键部分直接丢给老师一起分析，到时候直接看聊天记录。公式的话，我这个学科公式不是很复杂，手敲也不是很累。


#### 3. 排版与导出困境 (15 min)
* 您对 LaTeX 的接受程度如何？如果不用 LaTeX，您是如何保证论文符合学校/期刊格式要求的？
* 在处理 Word 模板（如页眉页脚、目录、公式对齐）时，您平均耗时多久？
* **核心假设验证**：如果有一个工具能让你像写 Markdown 一样简单，但导出来的结果 100% 符合学校 Word 模板，你愿意为此支付多少迁移成本（学习时间）？

A、不用，直接招学校发的论文格式调 模板一般就几分钟 写的时候一般已经改好了 
如果要改的话都是给导师看后再指出问题再改
能100%复合模版的话感觉学一两个小时吧，真有的话希望不要搞太复杂 本来就是方便学生的工具有感觉吗
B、latex没用过，格式刷万岁


#### 4. AI 辅助与隐私态度 (10 min)
* 您平时会把论文初稿或未发表的想法发给在线 AI（如 ChatGPT）寻求改进建议吗？
* **敏感度探测**：您是否担心在线 AI 导致您的研究思路泄露？如果有一个“完全断网也能用”的学术助手，对你来说是“必选项”还是“加分项”？
* 您希望 AI 帮你做摘要，还是帮你检查逻辑错误（比如：前文说 A，后文结论是 B）？

A、不会让ai给建议 一般是让ai结合我的数据、提示词生成初稿自己改，给老师看后根据修改建议再改
断网助手应该是必选项吧
只用做摘要就好，逻辑错误写的时候一般人都会自己想想吧，感觉现在单纯让ai写更容易有逻辑错误呢
B、初稿部分给ai，想法会给ai，但还要和他辩论就比较难说 完全断网也能用的助手不限时，很多东西我需要他上网自己找，我个人而言需要的是一个和我平级或者高级的“对话者”。

#### 5. 展望与总结 (5 min)
* 如果我们要开发一个“学术 IDE”，你最希望它的主界面长什么样？（极简 VS 像 VS Code 一样全能）
* 除了我们刚才聊到的，还有什么“小而痛苦”的细节是你希望解决的？


A、全能
B、学术ide的话还是干净一点好，点进去太多按钮看起来就让人望而却步 剩下没什么了


C、我觉得你这个需求有点问题，起码我看着有点怪，因为假如搞科研，写论文的话，基本上不会存在说用word去排版公式的这个需求。 我觉得如果你能做到查看pdf，可以一键导出word或者latex格式的公式。这个是蛮有用的，但这个应该有点难。 不过或许也可以立大专c，直接把整个论文的部分上下文给他，然后还有公司的文字识别出来的部分，直接让模型自己去推导，也有可能能够识别出一部分公式

# 1. 文献管理与引用集成 (Literature Management & Citation)

## 需求
深度集成主流写作软件，实现自动引用与元数据同步。
## 原文依据
"I used Docs for my grad degrees, and would like to add that Paperpile is a fantastic citation manager that interfaces almost exclusively with Google services (Docs, Drive, Scholar, etc)."
"Secondly, word integration for easy citation." 

## 需求
高效的 PDF 元数据提取与基于 DOI 的信息查询。
## 原文依据
"So first and foremost, easy metadata extraction from PDF files (Papers) as most citation managers have. Also metadata lookup based on DOI." 

## 需求
灵活的标签与文件夹管理系统，支持“超标签”移动文件。
## 原文依据
"Have tags and add tags based on certain subfolders, as well as, if I give a 'specific folder tag' to a paper that it then moves the paper to that subfolder." 

# 2. 文档编写与格式排版 (Writing & Formatting)

## 需求
支持将类 Markdown 的简单标记 100% 转换为特定期刊或学校的 Word/LaTeX 模板。
## 原文依据
"How does this change for journal submission if you’ve used a tool like Research Rabbit?"
"I think the longer your dissertation the harder the system struggles. Longer learning curve with it but would have been better to learn 8 years ago." (反映了对简化排版系统的潜在需求)

## 需求
在编辑器内直接查看、批注 PDF，并支持公式提取。
## 原文依据  
"One of my favorite parts is the ability to view and annotate PDFs within the application, a capability I have not been able to find elsewhere." 

# 3. AI 辅助科研功能 (AI-Powered Features)

## 需求 
利用 AI 进行研究问题验证、海量文献检索与总结。
## 原文依据  
"Validate the research question with Consensus AI."
"I’m just discovering AI tools like Research Rabbit, Elicit, Concensus, Perplexity etc."

## 需求 
深度逻辑一致性检查，而非仅限于语法润色。
## 原文依据  
"It cuts through the clutter and gives me what I need." (用户期望 AI 能够从杂乱信息中提取核心逻辑)

# 4. 工作流集成与多端同步 (Workflow Integration & Sync)

## 需求  
与第三方云服务（OneDrive, GDrive, Dropbox）无缝联动，并保持本地目录结构。
## 原文依据  
"Integration with a cloud server, preferably Onedrive (work/University)... I want to be able to download a file to my computer into a folder... I want the folder to be the actual storage location, so that I can keep my own folder structure." 

## 需求
连接碎片化想法，构建知识图谱。
## 原文依据  
"Use something like Obsidian or Notion to connect ideas?"

# 5. 本地化、离线与隐私保护 (Localization & Privacy)

## 需求
支持全功能离线模式，确保在无网络环境下（如飞机上）仍能访问和编辑论文与文献。
## 原文依据  
"The other reason is that should I ever lose access to my account I still would want to be able to access all the papers, this should also allow me to work when offline (airplane)." 

## 需求  
本地优先的性能与安全性。
## 原文依据  
"This way, everything is automatically backed up and I can still run TeX locally (much faster than Overleaf)."
"My biggest fear is my computer crashing and losing all of my work."

# 6. 用户体验与性能 (UI/UX & Performance)

## 需求 
直观易用的 UI，降低学习曲线。
## 原文依据  
"An usable UI, should be somewhat intuitive, most of the citation managers do this well, except for a few, Cough endnote." 

## 需求  
跨平台支持（尤其是移动端查看）。
## 原文依据
"Allow access to my files on phone through an App."

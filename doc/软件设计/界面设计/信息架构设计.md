# WeaveDoc 信息架构设计（Information Architecture）

---

# 全局导航结构

WeaveDoc 为桌面客户端应用（Avalonia UI），采用**单窗口多面板**架构。全局导航由以下固定区域构成：

```
┌─────────────────────────────────────────────────────────┐
│ 标题栏                                                    │
├─────────────────────────────────────────────────────────┤
│ 菜单栏    File  Edit  View  AI  Literature  Export  Help │
├─────────────────────────────────────────────────────────┤
│ 工具条    [新] [开] [存] [导出] [AI] [撤销] [重做]        │
├──────────────────────────────┬──────────────────────────┤
│        工作区 (Workspace)     │  上下文面板 (Context)     │
│  ┌──────────┐ ┌──────────────┐ │  可切换:                 │
│  │ PDF 阅读器 │ │ Markdown 编辑器│ │  · AI问答               │
│  │          │ │              │ │  · 文献列表              │
│  │          │ │              │ │  · 快照时间轴            │
│  └──────────┘ └──────────────┘ │                          │
├──────────────────────────────┴──────────────────────────┤
│ 状态栏    光标位置 | 文档字数 | 引用计数 | 同步状态 | AI模型状态 | 内存占用 │
└─────────────────────────────────────────────────────────┘
```

### 导航层级定义

| 层级 | 类型 | 说明 | 用例 |
|------|------|------|------|
| **L0 — 全局菜单栏** | 常驻 | 始终可见，菜单驱动，覆盖所有功能入口 | File / Edit / View / AI / Literature / Export / Help |
| **L1 — 工具条** | 常驻 | 高频操作的图标化入口（≤7 个按钮），3 次点击内触达核心功能 | 新建、打开、保存、导出、AI 面板开关 |
| **L2 — 工作区** | 常驻 | 内容生产的主区域，双屏分栏布局，不可关闭 | PDF 阅读器 + Markdown 编辑器 |
| **L3 — 上下文面板** | 可切换/可折叠 | 右侧辅助信息区，按需显示，与当前任务上下文联动 | AI 问答 / 文献列表 / 快照时间轴 |
| **L4 — 状态栏** | 默认常驻，可隐藏 | 系统级实时状态指标；状态值只读，部分状态项可点击跳转关联面板 | 光标位置、文档字数、引用计数、同步状态、模型状态、内存 |
| **M — 模态窗口** | 临时 | 阻塞式对话框，完成特定原子任务后关闭 | 导出对话框、设置、首次配置向导、帮助/关于 |

# 页面地图

## 1. 工作台（Workspace）— 主页面

| 属性 | 内容 |
|------|------|
| **类型** | 主页面（应用启动后的常驻视图） |
| **目标** | 为用户提供不间断的"文献阅读 + 论文写作"一体化工作环境 |
| **核心信息** | PDF 原文内容、Markdown 编辑文本、双屏同步状态、引文预览 |
| **入口来源** | 系统启动后默认进入；通过菜单栏 File → New/Open Workspace 创建工作区；工作区内 Markdown 文档通过 File → New/Open Markdown Document 或 MD 空态入口创建/打开 |

### 子区域 1-A：PDF 阅读器面板（左分屏）

| 属性 | 内容 |
|------|------|
| **类型** | 工作区子面板（可调整宽度，不可关闭） |
| **目标** | 提供 PDF 文献的阅读、浏览、缩放、区域框选能力 |
| **核心内容** | PDF 页面渲染、页码指示器、缩放滑块、选区高亮框 |
| **用户进入原因** | 阅读参考文献；对照原文位置进行锚点标记；框选公式区域用于 OCR 提取 |

### 子区域 1-B：Markdown 编辑器面板（右分屏）

| 属性 | 内容 |
|------|------|
| **类型** | 工作区子面板（可调整宽度，不可关闭） |
| **目标** | 提供 Markdown 正文的编辑、语法高亮、引用标记内联预览 |
| **核心内容** | 文本编辑区、行号、语法高亮、引用标记 tooltip、锚点链接渲染 |
| **用户进入原因** | 撰写论文正文；插入/编辑文献引用标记；粘贴公式 LaTeX 代码；点击锚点跳转至 PDF 对应位置 |

## 2. AI 问答面板（Chat Panel）— 上下文面板

| 属性 | 内容 |
|------|------|
| **类型** | 上下文面板（右侧可切换面板，可折叠） |
| **目标** | 提供基于已加载 PDF 文献的离线 RAG 问答交互 |
| **核心信息** | 对话历史、当前回答（流式）、引用溯源链接、模型状态 |
| **入口来源** | 工具条"AI 面板"按钮；菜单栏 View → AI Chat Panel；快捷键 `Ctrl+Shift+A` |

### 子区域 2-A：对话视图

| 属性 | 内容 |
|------|------|
| **类型** | 面板内容区 |
| **目标** | 展示问答对话历史，支持追问 |
| **核心内容** | 用户问题气泡、AI 回答气泡（含引用标注）、流式输出逐 Token 渲染 |

### 子区域 2-B：输入区

| 属性 | 内容 |
|------|------|
| **类型** | 面板内固定底部区域 |
| **目标** | 接收用户自然语言问题输入 |
| **核心内容** | 文本输入框、发送按钮、停止生成按钮 |

### 子区域 2-C：模型状态指示器

| 属性 | 内容 |
|------|------|
| **类型** | 面板顶部状态条 |
| **目标** | 告知用户当前 AI 模型加载/卸载状态及推理性能指标 |
| **核心内容** | 模型名称（如 Phi-4 7B）、状态灯（加载中/就绪/未加载）、推理速度（tokens/s）、内存占用 |

## 3. 文献列表面板（Literature Panel）— 上下文面板

| 属性 | 内容 |
|------|------|
| **类型** | 上下文面板（右侧可切换面板，可折叠） |
| **目标** | 展示已导入文献库的完整索引，支持搜索、筛选、与 PDF 文件匹配状态查看 |
| **核心信息** | 文献列表（作者、年份、标题、DOI）、匹配状态（已关联 PDF / 待匹配）、引用键 |
| **入口来源** | 菜单栏 View → Literature Panel；快捷键 `Ctrl+Shift+L` |

### 子区域 3-A：文献列表视图

| 属性 | 内容 |
|------|------|
| **类型** | 面板内容区 |
| **目标** | 浏览和检索所有已索引文献条目 |
| **核心内容** | 可排序紧凑列表（作者/年份/标题/引用键/PDF 匹配状态）、搜索过滤栏、条目数统计 |

### 子区域 3-B：文献详情行（内联展开）

| 属性 | 内容 |
|------|------|
| **类型** | 列表行内联展开 |
| **目标** | 查看单条文献的完整元数据字段 |
| **核心内容** | 全部 BibTeX 字段（abstract、keywords、journal、volume 等）、关联 PDF 文件路径、引用键 |

## 4. 快照时间轴面板（Snapshot Timeline Panel）— 上下文面板

| 属性 | 内容 |
|------|------|
| **类型** | 上下文面板（右侧可切换面板，可折叠） |
| **目标** | 提供文稿历史版本的可视化时间轴浏览与一键恢复能力 |
| **核心信息** | 快照节点列表（时间戳 + 变更摘要）、当前版本标记、快照总数 |
| **入口来源** | 菜单栏 View → Snapshot Timeline；快捷键 `Ctrl+Shift+T` |

### 子区域 4-A：时间轴视图

| 属性 | 内容 |
|------|------|
| **类型** | 面板内容区 |
| **目标** | 按时间倒序展示所有快照节点 |
| **核心内容** | 时间轴节点（时间戳、变更行数摘要、节点状态：可用/损坏） |

### 子区域 4-B：快照预览区

| 属性 | 内容 |
|------|------|
| **类型** | 面板底部可折叠预览区 |
| **目标** | 只读预览选中的历史版本内容 |
| **核心内容** | Markdown 只读预览（复用 MarkdownEditor preview/readOnly 变体）、恢复按钮、差异对比开关（280px 面板内使用 inline-compact diff） |

## 5. 导出对话框（Export Dialog）— 模态窗口

| 属性 | 内容 |
|------|------|
| **类型** | 模态窗口（阻塞式对话框） |
| **目标** | 引导用户完成"选择模板 → 选择格式 → 选择路径 → 确认导出"的原子操作流程 |
| **核心信息** | 模板列表、导出格式选项（Word/PDF）、完整输出文件路径、引文校验结果 |
| **入口来源** | 工具条"导出"按钮；菜单栏 Export → Export Document；快捷键 `Ctrl+Shift+E` |

### 子区域 5-A：模板选择区

| 属性 | 内容 |
|------|------|
| **类型** | 对话框内容区 |
| **目标** | 展示已注册的 AFD 模板列表，供用户选择目标排版规范 |
| **核心内容** | 模板列表（模板名称、适用院校/期刊、版本号）、模板预览摘要、模板有效性状态（Schema 校验通过/失败） |

### 子区域 5-B：导出配置区

| 属性 | 内容 |
|------|------|
| **类型** | 对话框内容区 |
| **目标** | 配置本次导出的格式与完整输出文件路径 |
| **核心内容** | 格式单选（.docx / .pdf）、完整输出文件路径选择器（Browse 按钮 + 路径显示，含文件名和扩展名） |

### 子区域 5-C：引文校验区

| 属性 | 内容 |
|------|------|
| **类型** | 对话框内容区 |
| **目标** | 展示导出前引用一致性校验结果 |
| **核心内容** | 引用匹配状态（`success` 全部匹配 / `warning` N 条未解析 / `error` 结构不一致）、未匹配引用列表、正文与文末参考文献一致性比对 |

### 子区域 5-D：进度与结果区

| 属性 | 内容 |
|------|------|
| **类型** | 对话框底部 |
| **目标** | 展示导出管线进度及最终结果 |
| **核心内容** | 阶段进度条（解析模板 → 生成 IR → 重排引文 → Pandoc 转换）、完成提示/错误详情 |

## 7. 首次配置向导（Setup Wizard）— 引导式模态

| 属性 | 内容 |
|------|------|
| **类型** | 模态向导（多步骤，仅首次启动时出现） |
| **目标** | 引导用户完成最低可行配置，使系统尽可能达到"可写作 + 可导出 + 可 AI 问答"的就绪状态；被跳过的配置项在完成页明确标记为暂不可用 |
| **核心信息** | 环境检测清单、模型配置、Zotero 关联、模板导入 |
| **入口来源** | 系统首次启动自动触发；菜单栏 Help → Setup Wizard 可手动重新打开 |

### 步骤 7-1：环境检测

| 属性 | 内容 |
|------|------|
| **目标** | 扫描系统环境，告知用户就绪情况 |
| **核心信息** | 检测清单：.NET Runtime、Pandoc、CPU AVX2 支持、可用内存 / 建议内存、磁盘可用空间；每项使用 `success` / `warning` / `error` 状态 |

### 步骤 7-2：模型配置

| 属性 | 内容 |
|------|------|
| **目标** | 引导用户获取本地 AI 模型 |
| **核心信息** | 模型类型选择（LLM / Embedding / OCR）、下载源/本地导入路径、按内存容量推荐的模型规格（7B/3B/1.5B） |

### 步骤 7-3：Zotero 关联

| 属性 | 内容 |
|------|------|
| **目标** | 建立与 Zotero 文献库的连接 |
| **核心信息** | `.bib` 文件路径浏览、跳过此步骤选项（稍后可配置） |

### 步骤 7-4：模板导入

| 属性 | 内容 |
|------|------|
| **目标** | 扫描内置模板并允许导入自定义 AFD 模板 |
| **核心信息** | 已注册模板列表、导入自定义模板入口、Schema 校验结果、跳过此步骤选项（稍后可配置） |

### 步骤 7-5：完成与进入工作台

| 属性 | 内容 |
|------|------|
| **目标** | 汇总配置结果，引导用户进入工作区 |
| **核心信息** | 配置摘要清单、进入工作台按钮 |

|------|------|

| **目标** | 展示版本信息、快捷鍵参考、审计日志入口 |

# 页面跳转关系

```
                    ┌──────────────────┐
                    │   首次配置向导     │
                    │  (仅首次启动)      │
                    └────────┬─────────┘
                             │ 完成配置
                             ▼
                    ┌──────────────────┐
              ┌─────│    工作台         │─────┐
              │     │  (常驻主页面)      │     │
              │     └──┬───┬───┬───┬──┘     │
              │        │   │   │   │        │
         Ctrl+,    Ctrl+  │   │   │  工具条按钮
              │     Shift+│   │   │        │
              │        A   │   │   │        │
              ▼            ▼   │   ▼        ▼
     ┌────────────┐ ┌────────┐│┌────────┐ ┌──────────┐
     │   设置      │ │AI问答  │││快照时间轴│ │导出对话框 │
     │  (模态)     │ │面板    │││面板     │ │ (模态)    │
     └────────────┘ └────────┘│└────────┘ └──────────┘
                              │
                              ▼
                       ┌────────────┐
                       │ 文献列表    │
                       │ 面板       │
                       └────────────┘

        PDF 阅读器框选公式 ──→ 公式提取浮动工具栏 (上下文浮层)
        F1               ──→ 帮助/关于 (模态)
```

### 跳转规则

| 从 | 到 | 触发方式 | 类型 |
|----|-----|---------|------|
| 工作台 | 导出对话框 | 工具条按钮 / 菜单 Export / `Ctrl+Shift+E` | 模态弹窗 |
| 工作台 | AI 问答面板 | 工具条按钮 / 菜单 View / `Ctrl+Shift+A` | 同窗口面板切换 |
| 工作台 | 文献列表面板 | 菜单 View / `Ctrl+Shift+L` | 同窗口面板切换 |
| 工作台 | 快照时间轴面板 | 菜单 View / `Ctrl+Shift+T` | 同窗口面板切换 |
| 工作台 | 设置 | 菜单 File → Settings / `Ctrl+,` | 模态弹窗 |
| 工作台 | 帮助/关于 | 菜单 Help → About / Help → Keyboard Shortcuts / `F1` | 模态弹窗（按入口聚焦对应分区） |
| 工作台 | 审计日志导出 | 菜单 Help → Audit Log / Help/About 底部链接 | 系统保存对话框；失败时回到 Help/About 模态 |
| PDF 阅读器 | 公式提取浮层 | 框选公式区域 | 上下文浮层（自动弹出） |
| 快照时间轴 | 快照预览 | 点击快照节点 | 面板内展开 |
| 导出对话框 | 导出进度 | 点击"导出"按钮 | 对话框内状态流转 |
| AI 问答面板引用链接 | PDF 阅读器 | 点击引用溯源链接 | 跨面板联动跳转 |
| Markdown 锚点链接 | PDF 阅读器 | 点击锚点链接 | 跨面板联动跳转 |
| PDF 区域点击 | Markdown 编辑器 | 点击 PDF 段落 | 跨面板联动插入锚点 |
| 任何页面 | 首次配置向导 | 首次启动自动 / 菜单 Help → Setup Wizard | 模态向导 |

# 高频用户路径

## 路径 1：写作 → 导出（最高频核心闭环）

```
工作台 (Markdown 编辑)
  │  插入引用标记 [@key]
  │  系统自动匹配 BibTeX 条目 + 显示 tooltip 预览
  │
  ├─ 写作完成
  │
  ▼
工具条 [导出] 按钮 或 Ctrl+Shift+E
  │
  ▼
导出对话框
  ├─ 选择模板（如"武汉大学硕士论文"）
  ├─ 选择格式（.docx / .pdf）
  ├─ 选择完整输出文件路径
  ├─ 系统校验引文一致性
  │   ├─ success: 全部匹配 → 可导出
  │   ├─ warning: 普通未匹配 → 展示警告列表，可保留原始标记继续导出
  │   └─ error: 结构性不一致 → 阻断导出，返回修改

```

# AI 功能嵌入点

以下标注 AI 能力在 IA 中的具体嵌入位置和交互方式：

| 嵌入点 | 所在页面/面板 | AI 能力 | 触发方式 | 交互形态 |
|--------|-------------|---------|---------|---------|
| **AI 问答面板** | 上下文面板（右侧） | RAG 检索增强生成 | 用户点击工具条按钮 / `Ctrl+Shift+A` 打开面板，输入问题 | 独立面板，对话式交互，流式输出，引用溯源链接可跨面板跳转 |
| **公式提取浮层** | PDF 阅读器上方 | OCR 公式识别 → LaTeX | 用户在 PDF 中框选公式区域后自动弹出 | 上下文浮层，展示识别结果 + 点击复制，无模态阻塞 |
| **模型状态指示器** | AI 问答面板顶部 / 状态栏 | 模型生命周期管理 | 系统自动感知（加载/卸载/推理） | 常驻状态指示，颜色编码状态灯 + 性能指标（tokens/s、内存） |
| **模型管理** | 设置 → 模型管理标签页 | 模型下载/切换/卸载 | 用户进入设置页面 | 配置界面，列表 + 操作按钮，模型下载有进度反馈 |
| **向量化进度** | AI 问答面板内（隐式） | PDF 文本分块 + Embedding 向量生成 | 导入 PDF 时自动触发，面板内显示进度 | 进度条 + 文案（"正在索引文档... X/Y 页"），非阻塞 |
| **内存水位告警** | 状态栏 | 内存监控与预警 | 默认阈值下系统内存占用 70–80% 时橙色预警，>80% 时红色告警；若用户修改阈值，则 warning 区间随 critical 阈值前移 | 状态栏颜色变化 + tooltip 建议操作；超过 critical 阈值时同时弹出 toast |

### AI 功能与 IA 的耦合原则

1. **AI 不阻断核心写作流** — 所有 AI 功能（问答、OCR、向量化）均在辅助面板或浮层中运行，不阻塞 Markdown 编辑器和 PDF 阅读器
2. **AI 状态显性化** — 模型加载/推理/空闲状态在状态栏和面板顶部双重可见，避免用户猜测"AI 是不是卡了"
3. **AI 输入输出局部化** — AI 问答面板的引用溯源链接与 PDF 阅读器双向联动，但 AI 面板本身可随时折叠，不影响写作空间
4. **AI 配置集中化** — 所有模型下载、切换、卸载操作收敛在设置页的"模型管理"标签页，不与写作/阅读工作流混合

# WeaveDoc — Design System（布局规则与设计系统）

---

## 0. 文档权威边界

当多个文档描述同一对象时，按以下优先级取值，避免重复定义继续分叉：

| 重复内容 | 权威来源 | 说明 |
|----------|----------|------|
| 精确 token 值（颜色、字体、间距、圆角、阴影、z-index、动画时长） | `visual-assets.json` | Avalonia ResourceDictionary 应从此文件生成 |
| 全局布局尺寸、响应式规则、组件尺寸、状态/错误/AI 设计规则 | 本文档 | 页面文档不得覆盖这些硬性约束 |
| 组件输入参数、状态机、子组件、复用场景 | `UI组件定义.md` | 页面中使用组件时应引用这里的 contract |
| 页面内模块顺序、页面局部文案、页面状态示例 | `页面定义.md` | 只定义页面组合，不重新发明组件 |
| 导航入口、页面关系、高频路径 | `信息架构设计.md` | 快捷键和入口应与页面定义保持一致 |
| 业务任务步骤、异常处理、完成状态 | `用户任务流分析.md` | 不覆盖 UI 尺寸和组件 contract |

## 1. 设计原则（Design Principles）

| 原则 | 定义 | 来源 |
|------|------|------|
| **内容优先，界面退让** | Chrome 尽可能小，工作区面积最大化。工具条 ≤7 个按钮，面板可折叠 | NFR-01 极简UI认知负荷 |
| **信息密度优先** | 学术工作台不是 Landing Page——使用紧凑间距、小字号、高密度列表，避免无意义留白 | 领域特征 |
| **状态显性化** | 关键状态必须有明确位置：AI 模型状态在 StatusBar + AI 面板顶部双重可见；内存占用在 StatusBar + 设置页可见；双屏同步/Zotero 状态在 StatusBar + 对应面板可见。禁止无用户授权的静默加载；若用户已在 Settings → Model Management 开启"AI 面板自动加载"，打开 AI 面板时仍必须展示加载进度 | 高风险体验点 |
| **离线优先** | 核心写作、阅读、导出、AI 推理均可离线完成；不显示常驻 online/offline 状态。下载模型、检查更新等联网动作必须由用户显式触发 | NFR-03 |
| **操作可逆** | 所有破坏性操作（恢复快照、删除模型、清空对话）均需二次确认。恢复操作前自动生成保护性快照 | 高风险体验点 |
| **AI 不阻断写作流** | AI 问答、OCR、向量化均在辅助面板或浮层中运行，不阻塞编辑器主线程，不弹出模态阻断 | AI 耦合原则 |

## 2. 窗口与响应式规则

### 2.1 窗口尺寸

| 属性 | 值 |
|------|-----|
| 默认窗口尺寸 | 1440 × 900 px |
| 最小窗口尺寸 | 1024 × 700 px |
| 标题栏高度 | 32 px（系统原生） |

### 2.2 断点行为

| 断点 | 行为 |
|------|------|
| ≥ 1440px | 默认展开上下文面板，完整三栏：PDF (35%) + MD（剩余宽度）+ 上下文面板 (280px) |
| 1024–1439px | 上下文面板默认折叠；用户展开时先预留 280px 面板宽度，再在剩余宽度内计算 PDF/MD 分屏 |
| < 1024px | 不允许。窗口不可缩至此尺寸以下 |

### 2.3 分屏比例规则

| 状态 | PDF 阅读器 | Markdown 编辑器 | 上下文面板 |
|------|-----------|----------------|-----------|
| 面板折叠（1024–1439px 默认） | 35% | 65% | 0 |
| 面板展开（≥1440px 默认） | 剩余工作区的 35%（≥300px） | 自动填充（≥400px） | 280px |
| 用户拖拽后 | 范围 25%–50% | 自动填充 | 280px / 0 |

- 双击分隔线 → 重置为 35%:65%
- 拖拽到 <25% → 吸附到 25%
- 拖拽到 >50% → 吸附到 50%
- 展开上下文面板时，先从工作区宽度中扣除 280px，再应用 SplitPane 比例和最小宽度约束，确保 1024px 最小窗口下 PDF ≥300px、MD ≥400px。

## 4. 间距系统（Spacing Scale）

基于 **4px 基准网格**：

| Token | 值 | 用途 |
|-------|-----|------|
| `space-2` | 2px | 分隔线宽度、图标与文字紧贴间距 |
| `space-4` | 4px | 紧凑元素间距（列表内相同信息组的间距） |
| `space-8` | 8px | 默认内边距、组件内部间距、消息气泡间距 |
| `space-12` | 12px | 面板内边距、表单字段间距 |
| `space-16` | 16px | 模块间距、对话框内分区间距 |
| `space-24` | 24px | 页面级分区间距、对话框内容区到边缘 |
| `space-32` | 32px | 大分区间距（极少使用） |

### 4.1 具体应用

| 位置 | 水平 padding | 垂直 padding |
|------|-------------|-------------|
| 工具条按钮 | 8px（按钮之间） | 8px（上下居中于 40px 容器） |
| 上下文面板内容区 | 12px | 12px |
| 对话框内容区 | 24px | 16px |
| 消息气泡（AI 面板） | 8px（气泡之间） | — |
| 列表行（文献/模板） | 12px | 8px（行内上下） |
| 状态栏项 | 12px（项之间） | — |

## 5. 面板层级与 Z-Index 体系

```
Z-Index 栈（由低到高）:
─────────────────────────────────
Z0  工作区背景           基础层
Z1  PDF 阅读器 / MD 编辑器   内容层
Z2  分隔线（SplitDivider）   交互层（hover 高亮）
Z3  上下文面板             可折叠辅助层
Z4  搜索替换栏（编辑器内浮动） 临时浮层
Z5  公式提取浮动工具栏       上下文浮层（最高非模态层）
────────────────── 遮罩层 ──────────────────
Z10 模态遮罩 Overlay       半透明黑色 rgba(0,0,0,0.4)
Z11 模态窗口               导出对话框、设置、向导、帮助/关于
Z12 全局确认对话框（ConfirmDialogHost） 用于工作区/面板破坏性确认；若来源在模态内，则作为模态中的模态
Z13 Toast 通知            非阻塞全局顶层
─────────────────────────────────
```

### 5.1 面板折叠动画

| 动画 | 时长 | 缓动 |
|------|------|------|
| 上下文面板展开 | 200ms | ease-out |
| 上下文面板折叠 | 150ms | ease-in |
| 模态打开 | 200ms | ease-out (fade-in + scale 0.97→1) |
| 模态关闭 | 150ms | ease-in (fade-out) |
| Toast 进入 | 200ms | ease-out (从底部 slide-up) |
| Toast 退出 | 200ms | ease-in (fade-out) |

## 6. 字体系统（Typography）

### 6.1 字体族

| 用途 | 字体 | Fallback |
|------|------|---------|
| UI 文字（全局） | Segoe UI (Win) / Noto Sans (Linux) | system-ui, sans-serif |
| 代码 / Markdown 编辑 | JetBrains Mono | Fira Code, Cascadia Code, Consolas, monospace |
| PDF 内容渲染 | 衬线字体（PDF 内嵌） | — |

### 6.2 字号阶梯

与 `visual-assets.json` §typography.scale 对齐。

| Token | 大小 | 行高 | 字重 | 用途 |
|-------|------|------|------|------|
| `Caption` | 10px | 14px | 400 | 状态栏、微 tooltip、OCR 置信度、时间戳（等宽） |
| `Body Dense` | 11px | 16px | 400 | 引用芯片、侧边栏列表项、文件树、状态栏文本 |

| `Body Regular` | 13px | 20px | 400 | **核心应用字号**：文献列表、对话气泡、表单标签、设置正文 |
| `Code Editor` | 14px | 22px | 400 | Markdown 编辑器、LaTeX 代码块、等宽文本 |
| `Panel Header` | 11px | 12px | 700 | 侧边栏 chrome 标签（如 "EXPLORER"）、大写面板标题 |

### 6.3 字重

| Token | 值 | 用途 |
|-------|-----|------|

## 8. 信息层级系统

### 8.1 视觉层次（由强到弱）

```
L0 — 主操作按钮                导出按钮（Primary，唯一强色按钮）
L1 — 激活/选中态               当前 Tab、选中行、当前快照节点
L2 — 交互元素                  菜单项、工具条按钮、链接、可点击状态项
L3 — 内容正文                  Markdown 文本、PDF 内容、AI 回答正文
L4 — 辅助信息                  状态栏、模型指标、引用计数、时间戳
L5 — 占位/引导                 空状态文案、placeholder、示例问题
L6 — 禁用态                    灰色不可用的按钮、模板、菜单项
```

### 8.2 用户焦点模型

```
启动 / 打开工作区:
  焦点 → Markdown 编辑器（最高频操作）

打开 AI 面板:
  焦点 → 输入框

打开导出对话框:
  焦点 → 模板列表（第一项预选）

打开设置:
  焦点 → 第一个可修改控件

打开快照时间轴:
  焦点 → 时间轴列表
```

### 8.3 视觉权重分配

| 元素 | 视觉权重 | 策略 |
|------|---------|------|
| 导出按钮 | 最高 | 工具条中唯一使用主色填充的按钮 |
| 当前选中项 | 高 | 蓝色/深色背景高亮 |
| AI 回答中的引用链接 | 中高 | 蓝色可点击 CitationChip，标签格式统一为 `[1] p.3`；多条引用按芯片顺序排列 |
| Tab 激活下划线 | 中 | 2px 底部强调色线 |
| 分隔线 | 极低 | 2px 细线，仅功能性存在 |
| 面板外边框 | 无 | 面板不画完整外框；必要分隔线使用 Border token |

## 9. 交互模式规范

### 9.1 悬停（Hover）

| 目标 | 延迟 | 效果 |
|------|------|------|
| 工具条按钮 | 即时 | 背景微变 + tooltip（含快捷键）在 400ms 后出现 |
| 分隔线 | 即时 | 鼠标变为 ↔，分隔线高亮 |
| 列表行 | 即时 | 背景微变 |
| 状态栏可点击项 | 即时 | 鼠标变为 pointer，下划线出现 |
| 引用标记 `[@key]` | 300ms | tooltip 弹出文献预览卡片 |
| 引用溯源链接 | 即时 | 下划线 + 鼠标 pointer |
| 内存指示器 | 即时 | tooltip 显示详细分配 |

### 9.2 点击（Click）

| 目标 | 行为 |
|------|------|
| PDF 段落 | 生成锚点 → MD 编辑器光标处插入锚点链接（延迟 <30ms） |
| MD 锚点链接 | PDF 跳转到对应页面 + 高亮段落 |
| AI 引用溯源链接 | PDF 跳转到对应页码 + 高亮段落 |
| 状态栏 "Refs: N" | 打开文献列表面板 |
| 状态栏 "Sync On/Off" | 切换双屏同步滚动状态 |
| 模型状态灯 | 跳转 Settings → Model Management |
| 双击分隔线 | 重置分屏比例为 35%:65% |
| 双击时间轴节点 | 弹出恢复确认对话框（快捷操作） |
| 双击文献行 | 在 MD 编辑器光标处插入引用键 |

### 9.3 拖拽（Drag）

| 目标 | 行为 |
|------|------|
| 分隔线 | 水平拖动，实时调整分屏比例，松手吸附边界 |
| PDF 公式框选 | 按下鼠标 → 拖拽 → 蓝色半透明矩形 → 松手触发 OCR |
| 文献行 | 拖拽到 MD 编辑器 → 插入引用键 `[@key]` |

## 10. AI 集成设计规范

### 10.1 AI 功能嵌入矩阵

| AI 功能 | 嵌入位置 | 形态 | 阻塞主流程 |
|---------|---------|------|-----------|
| RAG 问答 | 上下文面板（Tab 1） | 对话式面板，流式输出 | 否 |
| 公式 OCR | PDF 阅读器上方 | 浮动工具栏浮层 | 否 |
| 向量化索引 | AI 面板内隐式 | 进度条 + 文案 | 否 |
| 模型生命周期 | 状态栏 + AI 面板顶部 | 双位置状态灯 | 否 |
| 引文智能推荐（未来） | MD 编辑器 / 文献面板内 | 基于当前写作上下文推荐可能相关的文献候选；不替代 `[@` 规则补全 | 否 |
| 模型管理 | 设置 → 模型管理标签页 | 配置界面 | 不适用（用户主动进入设置模态） |

> 当前 `[@` 引用自动补全属于 CitationIndex 规则匹配能力，不计入 AI 功能；未来若接入语义推荐，按"引文智能推荐"扩展。

### 10.2 AI 状态灯规范

颜色值以 `visual-assets.json` §colors.aiStatus 为权威来源。

| 状态 | 颜色 | 动画 | 含义 |
|------|------|------|------|
| `unconfigured` | 灰色 `#888888` | 无 | 未配置任何模型 |
| `unloaded` | 红色 `#F85149` | 无 | 模型已配置但未加载 |
| `loading` | 黄色 `#D29922` | 旋转 | 模型加载中 + 百分比 |
| `idle` | 绿色 `#3FB950` | 静态 | 模型就绪，等待输入 |
| `inference` | 绿色 `#3FB950` | 呼吸脉冲 | 推理中，实时 tokens/s |

### 10.3 流式输出规范

| 属性 | 规范 |
|------|------|
| 首字响应时间 | < 2s（NFR-02 硬指标） |
| 逐 Token 动画 | 每个 Token 到达即渲染，光标闪烁（0.5s 间隔） |
| 引用溯源链接 | 流式完成后统一渲染在回答底部 |
| 用户滚动历史时 | 显示"↓ 回到底部"浮动按钮 |
| 停止生成 | Token 保留，标注 `[生成已停止]` |
| 错误降级 | 红色边框气泡 + 错误描述 + 操作建议 |

### 10.4 AI 面板内间距

```
┌─────────────────────────────┐
```

## 11. 状态管理规范

### 11.1 全局状态分类

| 类别 | 状态项 | 展示位置 |
|------|--------|---------|
| **文档状态** | 光标位置、字数、引用计数、未保存标记 | 状态栏左侧 |
| **AI 状态** | 模型名称、加载进度、推理速度、内存占比 | 状态栏右侧 + AI 面板顶部 |
| **同步状态** | 双屏同步滚动开关；Zotero 连接状态与上次同步时间（状态栏仅显示断连/警告入口，完整信息在文献面板操作栏） | 状态栏 + 文献面板操作栏 |
| **系统状态** | 内存占用 | 状态栏右侧 |
| **工作区状态** | 当前文档路径、工作区名称 | 标题栏 |

### 11.2 空状态规范

所有空状态遵循统一模板：

```
┌─────────────────────────┐
│                         │
│     [图标 (24×24)]       │  ← 可选，灰色
│                         │
│   主引导文案              │  ← Body Regular / weight-medium
│   辅助说明文案            │  ← Body Dense, MutedForeground（可选）
│                         │
│   [操作按钮] [次要按钮]   │  ← 默认至少一个操作入口；纯信息空态可为空
│                         │
└─────────────────────────┘
```

| 场景 | 主文案 | 操作按钮 |
|------|--------|---------|
| PDF 未加载 | "拖入 PDF 文献以开始阅读" | 打开文件 |
| MD 未加载 | "新建或打开 Markdown 文档以开始写作" | 新建 / 打开 |
| 文献列表空 | "暂无文献条目" | 导入 BibTeX / 连接 Zotero |
| 快照空 | "暂无快照。系统将每 5 分钟创建一次历史快照" | —（纯信息空态） |
| AI 模型未配置 | "请先在 Settings → Model Management 中下载并加载模型" | 跳转设置 |
| AI 空对话 | "基于你已加载的 PDF 文献提出问题" | 3 个示例问题（可点击） |
| 导出无可用模板 | "没有可用的排版模板" | 跳转模板库 |

### 11.3 加载状态规范

| 场景 | 形态 | 位置 |
|------|------|------|
| LLM 模型加载 | 进度条 + 百分比 + "Loading Phi-4 7B..." | AI 面板顶部 + 状态栏 |
| PDF 向量化索引 | 进度条 + "正在索引文档... 3/42 pages" | AI 面板消息列表顶部 |
| 大文档打开（>10000字） | 进度条 | MD 编辑器中央 |
| Pandoc 导出 | 阶段步骤条（4 步） | 导出对话框底部 |
| OCR 识别中 | 进度指示 + 阶段文案 + 取消入口；不可只显示无限 spinner | 公式浮层内 |
| Zotero 同步中 | 按钮旋转动画 | 文献面板操作栏 |
| 快照预览重建 | 骨架屏 + 阶段文案；耗时超过 1s 时显示取消/稍后重试入口 | 快照预览区 |

### 11.4 错误/警告状态

| 场景 | 形态 | 用户操作 |
|------|------|---------|
| 普通引文不匹配 | 校验区橙色展开 + 未匹配列表 | "返回修改" / "仍要继续导出" |
| 引文结构不一致 | 校验区红色展开 + 不一致原因，导出按钮禁用 | 返回修改 |
| Pandoc 转换失败 | 进度条中断 + 错误详情 + "原稿安全"声明 | 查看日志 / 重试 |
| LLM 推理失败 | AI 气泡红色边框 + 错误描述 | 缩短问题 / 清空对话 |
| OCR 识别失败 | "未能识别到公式，请重新框选" | 重新框选 |
| 模型文件损坏 | 红色状态灯 + "模型文件缺失或损坏" | 引导至模型管理 |
| 内存 >80%（默认 critical 阈值） | 状态栏内存红色 + toast 告警；若用户在 Settings 修改阈值，则以配置值为准 | 释放 PDF 缓存 / 切换小模型 / 关闭其他应用 |
| Zotero 断连 | 状态栏 `StatusIcon(warning)` + 文献面板警告 | 重新配置路径 |
| 快照损坏 | 节点灰色不可点击 + tooltip 说明 | 其他节点正常可用 |
| AFD 模板 Schema 校验失败 | 模板行红色 + 展开错误详情 | 不可选择，需修复模板 |

## 15. 实现技术映射（Avalonia UI）

> **设计 Token 权威来源**：所有颜色、间距、字体、圆角、阴影的精确数值以 `visual-assets.json` 为准。Avalonia ResourceDictionary 中的 SolidColorBrush / Thickness / CornerRadius / BoxShadow 等资源应从 visual-assets.json 的 themeMapping 节生成。

| 设计概念 | Avalonia 实现 | 对应 visual-assets.json 节 |
|---------|---------------|---------------------------|
| 单窗口多面板 | `Window` + `Grid` 布局 + `GridSplitter` | §layout.workspace |
| MVVM 绑定 | `{Binding}` + `INotifyPropertyChanged` + CommunityToolkit.Mvvm | — |
| 响应式联动 | ReactiveUI `WhenAnyValue` | — |
| 分屏拖拽 | `GridSplitter` + `GridLength` 动态调整 | §layout.workspace.splitDivider |
| 模态窗口 | `Window.ShowDialog()` 或 overlay `Panel` | §layout.modalWindows, §layout.zIndex |
| Tab 切换 | `TabControl` / `TabStrip` + `ContentPresenter` | — |
| 图标 | `PathIcon` / `SvgImage`（单色路径数据） | §iconography |
| 等宽字体编辑 | `TextEditor`（AvaloniaEdit） | §typography.fontStacks.code |
| 上下文浮层 | `Popup` / `Flyout` | §layout.zIndex.Z5 |

| 主题切换 | Avalonia ThemeVariant (Light/Dark) | §themeMapping |

| 阴影 | `BoxShadow` 属性 on `Border` | §elevation |
| 圆角 | `CornerRadius` 属性 | §borderRadius |

## 16. 检查清单（Design Review Checklist）

每个新增页面 / 组件在评审时需验证以下条目：

- [ ] 已运行 `python3 界面设计/check-doc-consistency.py`，且输出 PASS
- [ ] 间距使用 4px 基准网格（无 3px / 5px / 7px）
- [ ] 按钮高度遵循 §7.1：IconButton / 标准 / Primary / Warning / Destructive 为 32px，TextButton / HyperlinkButton 为 24px
- [ ] 所有破坏性操作有 ConfirmDialog 二次确认
- [ ] 耗时操作（>1s）有明确的进度指示（非无限 spinner）
- [ ] AI 状态在 StatusBar 和面板顶部双重可见
- [ ] 操作型空状态有引导文案 + 至少一个操作入口；纯信息空态可无操作入口
- [ ] 引用溯源链接跨面板联动跳转正常（AI → PDF）
- [ ] 锚点链接跨面板联动跳转正常（MD → PDF）
- [ ] 模态窗口支持 Esc 关闭
- [ ] 模态遮罩不可点击关闭（防止误操作丢失数据）
- [ ] 错误提示明确声明数据安全边界：导出失败时说明"原稿安全"；恢复操作说明已先创建保护性快照
- [ ] 快捷键已在 Help → Keyboard Shortcuts 中注册
- [ ] 列表搜索"输入即过滤"，无需按 Enter
- [ ] 流式输出有"回到底部"按钮（用户滚动历史时）
- [ ] 分屏比例在窗口缩小时不打破最小宽度约束
